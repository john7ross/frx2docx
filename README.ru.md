# frx2docx

[English](README.md) · **Русский**

Конвертер **шаблонов FastReport (`.frx`)** и обычных документов в обе стороны.
Без установки, без внешних сервисов, без облака.

```
шаблон.frx                        →  .docx  и/или  .pdf
документ.docx / .pdf / .md / .txt →  шаблон.frx
```

Направление выбирается по расширению — отдельную команду запоминать не нужно.
Перетащите файлы на программу или укажите папку.

- **Язык:** Python 3.9+ (в комплекте лежит встроенный 3.14)
- **Обязательная зависимость:** `python-docx` — и всё
- **PDF:** MS Word или LibreOffice, если они есть, иначе **встроенный движок
  PDF на чистом Python** — со встраиванием настоящих TrueType и кириллицей
- **Платформы:** Windows (основная), Linux и macOS — всё, кроме пути через
  Word COM

## Зачем это нужно

Шаблон FastReport — это XML с абсолютно спозиционированными объектами. Юрист,
руководитель или аудитор его не прочитает, а ставить дизайнер FastReport ради
вычитки формулировок никто не будет. Программа превращает шаблон в документ
Word, который выглядит как печатная форма, и возвращает поправленный документ
обратно в шаблон.

Обратное направление важно не меньше прямого: отдали `.docx` юристам, получили
правки, сконвертировали в `.frx`, открыли в дизайнере — и подстановки
`[root.Field]` целы на всём пути.

## Требования к системе

| Что | Требуется |
|---|---|
| ОС | Windows 10 или 11, 64-бит. Linux и macOS — всё, кроме пути через Word COM |
| Место на диске | 60 МБ распакованного архива или 20 МБ одного `.exe` |
| Права администратора | не нужны |
| Интернет | не нужен: программа никуда не обращается |
| Visual C++ Redistributable | не нужен, нужный рантайм входит в саму Windows |
| Microsoft Word | **не обязателен** — им PDF получается точнее всего, но без него сработает встроенный движок |
| LibreOffice | **не обязателен** — используется, если нет Word |
| Шрифты | ставить не нужно, запасные едут в комплекте (см. ниже) |

## Установка

Если вы взяли релизный архив — ставить нечего: распакуйте, встроенный Python
уже внутри. Одиночный `frx2docx.exe` не требует и распаковки.

Из исходников:

```bash
pip install -r requirements.txt
python frx2docx.py template.frx
```

`qrcode` и `pywin32` необязательны: без них QR превращается в подписанную
рамку-заглушку, а PDF собирается через PowerShell COM или встроенным движком.

### Предупреждение SmartScreen при первом запуске

`frx2docx.exe` не подписан сертификатом разработчика — такой сертификат
покупается у центра сертификации и стоит денег. Поэтому при первом запуске
файла, скачанного из интернета, Windows покажет синее окно:

> **Система Windows защитила ваш компьютер**
> Фильтр SmartScreen Microsoft Defender предотвратил запуск неопознанного
> приложения.

Это **не** обнаружение вируса. SmartScreen так реагирует на любой неподписанный
файл, который ещё не набрал статистику запусков. Чтобы продолжить, нажмите
**«Подробнее»**, затем **«Выполнить в любом случае»**.

Если хотите убедиться сами:

- проверьте файл на [virustotal.com](https://www.virustotal.com) — там его
  посмотрят несколько десятков антивирусов;
- сверьте контрольную сумму с указанной на странице релиза:
  `Get-FileHash frx2docx.exe -Algorithm SHA256`;
- соберите `.exe` самостоятельно из исходников — `СОБРАТЬ EXE.bat`, весь код
  открыт;
- либо просто возьмите портативный архив: там нет `.exe` вовсе, только скрипты
  на Python, и SmartScreen на него не срабатывает.

При копировании файла по локальной сети или через общую папку предупреждения не
будет — оно появляется только у файлов с меткой «скачано из интернета».

## Шрифты

Встроенный движок PDF рисует текст настоящими TrueType, поэтому шрифт нужен
физически. Порядок поиска такой:

1. **Системные шрифты** — `C:\Windows\Fonts` и папка шрифтов пользователя.
   Если шаблон просит Arial и Arial в системе есть, берётся именно он.
2. **Запасные из комплекта** — папка `fonts/`, она же внутри `.exe`. Там лежат
   [Liberation](https://github.com/liberationfonts/liberation-fonts) (SIL Open
   Font License 1.1): Sans, Serif и Mono во всех четырёх начертаниях.

Liberation выбраны не случайно: они **метрически совместимы** с Arial, Times
New Roman и Courier New — ширина каждого символа совпадает до сотых, поэтому
подмена не сдвигает переносы строк и вёрстка остаётся прежней. Кириллица в них
есть.

Если шаблон просит шрифт, которого нет ни в системе, ни в комплекте, берётся
ближайший по назначению (с засечками → Liberation Serif, без засечек →
Liberation Sans, моноширинный → Liberation Mono) и печатается предупреждение с
именем шрифта. Свои шрифты можно просто положить в папку `fonts/`.

Путь `.frx → .docx` шрифты не читает вообще: имя шрифта записывается в
документ, а подбирает его Word.

## Как пользоваться

```bash
python frx2docx.py template.frx                 # → template.docx
python frx2docx.py template.frx --format both   # → .docx и .pdf
python frx2docx.py templates/ -r --format pdf -o OUT
python frx2docx.py договор.docx                 # → договор.frx
python frx2docx.py скан.pdf                     # → скан.frx
python frx2docx.py заметки.md                   # → заметки.frx
```

| Ключ | Значение |
|---|---|
| `-f, --format docx\|pdf\|both\|frx` | формат результата (по умолчанию `docx` для `.frx` и `frx` для остальных) |
| `--pdf` | то же, что `--format both` |
| `--engine auto\|word\|libreoffice\|builtin` | чем делать PDF; `auto` пробует Word, потом LibreOffice, потом встроенный движок |
| `-o, --outdir КАТАЛОГ` | куда складывать результат (по умолчанию — рядом с исходником) |
| `-r, --recursive` | искать файлы в подпапках |
| `--all-pages` | переносить и страницы `ReportPage` с `Visible="false"` (по умолчанию пропускаются — так же, как их не печатает FastReport) |
| `-v, --verbose` | показывать все предупреждения и полные трассировки |

Тем, кто не работает с командной строкой: дважды щёлкните
**`КОНВЕРТИРОВАТЬ.bat`** — он спросит формат, прочитает папку `IN` и запишет
результат в `OUT`. Файлы можно и просто бросить мышью на сам `.bat`.

## Что переносится

### `.frx` → `.docx` / `.pdf`

| Переносится | Подробности |
|---|---|
| `TextObject` | шрифт, кегль, начертание, цвет, выравнивание, поля, отступ первой строки, межстрочный интервал, перенос слов, поворот на 90°/270°, гиперссылки |
| `TableObject` | ширины колонок, высоты строк, `ColSpan`/`RowSpan`, границы и их толщина по сторонам, заливка, вложенные в ячейку объекты |
| `RichObject` | RTF разбирается по-настоящему: жирный, курсив, подчёркивание, зачёркивание, кегль, цвет, шрифт и выравнивание абзаца сохраняются |
| `PictureObject` | встроенный base64, файлы по `ImageLocation`, PNG/JPEG/BMP, `SizeMode` |
| `BarcodeObject` | QR, Code 128, EAN-13/8, Code 39, Interleaved 2 of 5 рисуются настоящими, когда содержимое — константа |
| `CheckBoxObject` | ☒ / ☐, в том числе внутри ячеек таблицы |
| `LineObject`, `ShapeObject` | горизонтальные и вертикальные линейки, прямоугольники с заливкой; остальные фигуры приближаются прямоугольником с предупреждением |
| `PageHeaderBand`, `PageFooterBand` | становятся настоящими колонтитулами Word и повторяются на каждой странице; поля страницы увеличиваются ровно на высоту колонтитула, поэтому тело сохраняет ту же высоту, что и в FastReport |
| `[Page]`, `[TotalPages]` | превращаются в поля Word `PAGE` / `NUMPAGES`, а во встроенном движке PDF подставляются настоящими номерами |
| Параметры страницы | размер листа, ориентация, поля, колонки, водяной знак; каждая `ReportPage` становится отдельной секцией Word |
| Разметка `HtmlTags` | `<b> <i> <u> <s> <sub> <sup> <font face size color>` превращаются в настоящее форматирование Word |

### Что НЕ переносится

- **`ScriptText`** — обработчики на C# (`BeforePrint` и прочие) не выполняются.
  То, что скрипт скрывает, показывает или подставляет во время печати, в
  результат не попадает. Объекты, которыми управляет скрипт, переносятся в том
  виде, в каком лежат в шаблоне, и об этом пишется предупреждение.
- **Данные** — `[root.Field]` остаётся текстом. Это конвертер шаблона, а не
  генератор отчёта.
- `SubreportObject`, `MSChartObject`, `MapObject`, градиентные и штриховые
  заливки (приближаются основным цветом), диагональные `LineObject`.

О каждом неподдержанном или приближённом объекте печатается предупреждение с
его именем — молча ничего не пропадает.

### `.docx` / `.pdf` / `.md` / `.txt` → `.frx`

| Источник | Что читается |
|---|---|
| `.docx` | секции и параметры страницы, абзацы с оформлением прогонов, развёрнутым через `styles.xml` (поэтому стилевые заголовки не теряются), выравнивание, отступы, интервалы, таблицы с объединениями/границами/заливкой, встроенные картинки, колонтитулы, поля `PAGE`/`NUMPAGES` → `[Page]`/`[TotalPages]` |
| `.pdf` | текст с абсолютными координатами, шрифты, кегли, начертание и цвет; линии и рамки; куски строк склеиваются обратно в строки и абзацы; геометрия страницы и `/Rotate` |
| `.md` | заголовки, абзацы, списки, таблицы в трубах, линейки, цитаты, `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` `` |
| `.txt` | абзацы, разделённые пустой строкой |

На выходе — шаблон, который открывается в дизайнере FastReport: `ReportPage` с
правильным листом и полями, `PageHeaderBand` / `DataBand` / `PageFooterBand` и
объекты `TextObject` / `TableObject` / `PictureObject`, расставленные по
посчитанным метрикам текста.

## Проверка вёрстки

```bash
python verify_layout.py templates/ OUT/
```

Сверяет для каждой статической надписи расстояние от левого края страницы в
шаблоне и в готовом PDF. Норма — медиана около 1 мм и пустой столбец «хвост».
Внешние программы не нужны: PDF разбирается тем же встроенным парсером.

Текущий результат на эталонном наборе из 11 боевых шаблонов: медиана
**0,01–0,55 мм**, надписей за порогом 3 мм нет.

## Тесты

```bash
python tests/test_frxkit.py        # 53 теста, около минуты
```

Юнит-тесты разбора атрибутов, RTF, штрихкодов, метрик, подмножеств и подмены
шрифтов,
табличной раскладки, лексера PDF и CMap; сквозные тесты, которые собирают
`.docx` и `.pdf`, читают их обратно и проверяют round-trip в обе стороны.
Тесты, которым нужны системные шрифты или локальная папка с примерами,
пропускают себя сами.

## Сборка дистрибутива

- **Портативная папка** — скопируйте каталог целиком, он несёт свой Python.
- **Один файл** — дважды щёлкните `СОБРАТЬ EXE.bat` (один раз понадобится
  интернет, чтобы скачать PyInstaller). Получится `dist/frx2docx.exe`, которому
  не нужно вообще ничего.

## О шаблонах и секретах

В боевом `.frx` обычно лежит `XmlDataConnection ConnectionString` —
зашифрованная, но всё же чувствительная строка подключения — и полный список
полей источника данных. Не кладите настоящие шаблоны в репозиторий; папки `IN/`
и `OUT/` внесены в `.gitignore` именно поэтому. Единственный шаблон в git —
`tests/data/features.frx`, он синтетический и без источника данных.

Сам конвертер никуда ничего не отправляет: ни сетевых обращений, ни телеметрии.
