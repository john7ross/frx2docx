# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [2.0.0] — 2026-08-01

Крупная переработка: конвертер стал двусторонним, обзавёлся собственным
движком PDF и перестал зависеть от внешних программ.

### Добавлено

- **Обратный конвертер**: `.docx`, `.pdf`, `.md`, `.txt` → `.frx`. Направление
  выбирается по расширению, отдельная команда не нужна.
  - `.docx` — секции, абзацы с разворотом стилей из `styles.xml`, таблицы с
    объединениями и границами, картинки, колонтитулы, поля `PAGE`/`NUMPAGES`.
  - `.pdf` — собственный парсер: объекты и потоки (Flate, LZW, ASCII85,
    ASCIIHex, RunLength, ObjStm, ксреф-потоки), шрифты с `ToUnicode` и
    `Differences`, интерпретация содержимого с матрицами, склейка кусков строк
    в абзацы, линии и рамки.
  - `.md` — заголовки, списки, таблицы, линейки, цитаты, inline-разметка.
- **Встроенный движок PDF** на чистом Python: встраивание TrueType с
  подмножеством глифов (CIDFontType2, Identity-H, `ToUnicode`), выключка по
  формату, разрыв длинных абзацев между страницами, картинки PNG/JPEG/BMP,
  водяные знаки. Включается сам, когда нет ни Word, ни LibreOffice, либо явно
  ключом `--engine builtin`.
- **Колонтитулы**: `PageHeaderBand` и `PageFooterBand` становятся настоящими
  колонтитулами Word и повторяются на каждой странице; поля страницы
  увеличиваются ровно на высоту бэнда, поэтому высота тела совпадает с
  FastReport.
- **`[Page]` и `[TotalPages]`** превращаются в поля Word и подставляются
  настоящими номерами во встроенном PDF.
- **Новые объекты**: `LineObject`, `ShapeObject`, `ZipCodeObject`;
  `PictureObject` из файла по `ImageLocation`.
- **Настоящие штрихкоды** для константного содержимого: Code 128, EAN-13/8,
  Code 39, Interleaved 2 of 5 (QR был и раньше).
- **`RichObject` с форматированием**: RTF разбирается целиком — начертание,
  кегль, цвет, шрифт и выравнивание абзаца, — вместо плоского текста.
- Поддержка `Padding`, `ParagraphOffset`, `LineHeight`, `WordWrap`, `Angle`
  (90°/270°), гиперссылок, водяных знаков, многоколоночных страниц, толщины
  границ по сторонам, `TextFill.Color`.
- **Запасные шрифты в комплекте** — папка `fonts/` с Liberation Sans, Serif и
  Mono (SIL OFL 1.1), они же внутри `.exe`. Метрически совместимы с Arial,
  Times New Roman и Courier New, поэтому подмена не сдвигает переносы строк.
  Системный шрифт по-прежнему в приоритете, запасной берётся, только если
  запрошенного в системе нет.
- Ключ `--all-pages`: переносить и страницы с `Visible="false"`.
- Пакет тестов `tests/test_frxkit.py` — 53 теста.
- `README.md` / `README.ru.md`, `ARCHITECTURE.md` / `ARCHITECTURE.ru.md`,
  `requirements.txt`, `.gitignore`. В README — разделы «Требования к системе»,
  «Шрифты» и «Предупреждение SmartScreen»: неподписанный `.exe` не должен
  выглядеть для пользователя как вирус.
- `УСТАНОВКА.bat` (офлайн-установка из `wheels/`) и `ТЕСТЫ.bat`.

### Изменено

- Монолит `frx2docx.py` (1585 строк) разложен на пакет `frxkit` из 17 модулей.
  Корневой скрипт остался точкой входа и работает по-прежнему.
- `КОНВЕРТИРОВАТЬ.bat` понимает оба направления; `START.bat` удалён как
  дубликат.
- `verify_layout.py` больше не требует `pdftotext` из poppler: PDF разбирается
  встроенным парсером. Заодно перестал считать за сдвиг красную строку.
- Страницы `ReportPage` с `Visible="false"` по умолчанию пропускаются — так же,
  как их не печатает FastReport.
- Экспорт в `.docx` стал плотнее: у пустых ячеек знак абзаца кеглем 1 pt, а
  технический абзац между таблицами больше не накапливает лишнюю высоту. На
  эталонном наборе это вернуло документы к исходному числу страниц.

### Исправлено

- Дублирующееся определение `find_soffice`.
- Ячейки таблицы с картинкой теряли заливку.
- Водяной знак в `.docx` не отображался в части сборок Word (WordArt заменён на
  надпись в VML-прямоугольнике).
- Незакрытые файловые дескрипторы при чтении `.frx`.
- Два исходника с одинаковым именем в одном запуске затирали результат друг
  друга; теперь второй получает суффикс `-2`.

## [1.0.0]

Первая версия: `.frx` → `.docx` и `.pdf` через MS Word или LibreOffice,
`TextObject`, `TableObject`, `RichObject` плоским текстом, `PictureObject`,
`CheckBoxObject`, QR-коды, проверка вёрстки через `pdftotext`.
